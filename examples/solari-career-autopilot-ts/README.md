# Solari CareerOps Autopilot (TypeScript)

Autonomous AI Job Application Agent built on Solari. Demonstrates how an AI career copilot uses:
1. **Solari MicroVM Sandboxes**: Compile tailored application materials, skill-gap analysis, and portfolio proof points.
2. **Solari Stealth Cloud Browsers**: Bypass anti-bot protections on job boards, fill application forms, and capture `rrweb` DOM session recordings as verifiable proof of submission.

## Setup & Run

```bash
cp .env.example .env
# Add your SOLARI_API_KEY
npm install
npm start
```
